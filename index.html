Frequently asked questions

What is AI metadata?

AI metadata is hidden info saved inside an image file by AI tools. It can say which tool made the image (like ChatGPT, Midjourney, Gemini or Adobe Firefly), include a “made with AI” label, the prompt you typed, and device or location details. You can’t see it in the picture, but anyone can read it from the file.

Is this AI metadata remover really free?

Yes, it’s 100% free. There’s no sign-up, no daily limit and no watermark. Because everything runs in your own browser, there are no servers to pay for, so we can keep it free.

How do I remove AI metadata from an image?

Drag your images into the box at the top of this page. The tool removes the hidden info right away. Then click “Download” for one image, or “Download all” to get every cleaned image at once.

Are my images uploaded anywhere?

No. Everything happens inside your own browser. Your images never leave your computer, and the tool even works offline.

Does it reduce image quality?

No. For JPG, PNG and WebP files, only the hidden info is removed and the picture itself stays exactly the same. Other formats like HEIC and AVIF are saved as a fresh copy, which drops all hidden info. If you turn on “Make each image unique”, the image is re-saved with tiny changes you can’t see.

Which image formats are supported?

JPG, PNG and WebP are cleaned with zero quality loss. HEIC, AVIF, GIF, BMP and TIFF also work, and are saved as JPG or PNG.

Can it remove invisible AI watermarks like SynthID?

No. Some AI tools, like Google’s, hide an invisible watermark inside the picture itself. That is part of the image, not hidden file info, so no metadata remover can take it out.

What does “Make each image unique” do?

It makes tiny changes to the picture that your eyes can’t see, so the file no longer matches the original exactly. This helps against simple duplicate checks. It does not stop reverse image search (like Google Lens), because those look at what the picture shows.
