Frequently asked questions

AI metadata is invisible provenance information embedded directly inside an image file by generative AI tools like ChatGPT (DALL-E), Midjourney, Adobe Firefly, and Google Imagen. C2PA (Coalition for Content Provenance and Authenticity) manifests cryptographic tags that prove an image was made with AI, often containing the generator software, creation timestamp, and the exact prompt entered.

Social media platforms automatically detect AI images by scanning file metadata for C2PA manifests, JUMBF blocks, and IPTC 'trainedAlgorithmicMedia' digital source tags. By running your image through Reozix AI Metadata Remover before uploading, these provenance markers are completely purged, preventing platforms from automatically attaching 'Made with AI' warning badges.

No. Everything runs 100% locally in your web browser memory using HTML5 ArrayBuffers and Web Workers. Your images never leave your computer, no telemetry or file copies are saved, and the tool functions completely even when your internet connection is turned off.

Yes. Stable Diffusion, Automatic1111, Forge, and ComfyUI store prompts, negative prompts, CFG scales, seed numbers, and complete node graph workflows inside PNG text chunks (tEXt, iTXt, zTXt) and UserComment EXIF tags. Reozix thoroughly wipes these chunks so your creative recipes stay private.

No. Tools like Google SynthID inject imperceptible mathematical variations directly into the pixel values rather than storing file metadata. No metadata scrubber can remove pixel-level steganographic watermarks without modifying the visible image itself. However, Reozix removes all file-level markers (C2PA, IPTC, EXIF) that typical scanners inspect.

The 'Make each image unique' option introduces microscopic, imperceptible pixel adjustments (±1 on random color channels) across visible areas. This modifies the file's cryptographic hash (MD5, SHA-256) so simple automated duplicate checks will view the file as brand new.
